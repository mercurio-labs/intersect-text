# Call-free relative-closure controls

These are authored native algorithm controls with imported Ecore, not an
independent Xtext oracle or a reduction of an original full grammar.

The same nonnullable, rule-call-free Leaf has twenty literal branches. Two
otherwise identical callers have different actual call sites and final
suffixes. ManyCallers has ninety sequential calls per branch; Small has three.
The intended utility witness is ordinary native admission under the unchanged
10,000 pool with NativeV75, and the explicit NativeV74 recursive-analysis denial
for the same many-caller source. These expectations remain unqualified until
runtime qualification; they are not a saving forecast for original SysML.

NativeV75 alone may replay completed call-free nonnullable relative prefixes
from the existing proof-closure walker, retaining the complete real caller
stack and alternative. It does not cache final recursive-conflict results or
replace Full operand recognition, actions, recovery or model construction.
All previous profiles and public Legacy proof APIs remain unchanged.

The private cache is invocation-local. Lookup, miss traversal, token retention,
stop validation, publication and replay consume the same original pool before
work. Malformed or exhausted misses are never cached; nullable/accepting
results fall back without refund. These are unit bounds, not allocator bytes.
Actual raw-WASM/browser execution and original V75 admission are not yet run.
