# Inferred provider contexts

Frozen native extension controls against baseline `066ad510`. This directory
keeps the original source requests and actual old release-WASM failures separate
from subsequent explicit context counterparts. These are not additional pinned
Xtext/JVM oracle outcomes and do not establish full X03 or parameter qualification.

- `cases.json` and `before.json`: original four requested graphs. RGB defaults
  require an installed converter. Computed-setting contracts alone cannot provide
  missing read semantics.
- `behavior-cases.json` and `behavior-before.json`: explicit exact Rcore projection
  sources, dependency admission and retained behavior selection. The projection
  delegates read and write plans to the existing shared implementation.
- `behavior-entry-cases.json` and `behavior-entry-before.json`: initial dual-entry
  attempt retaining the native missing-argument rejection.
- `behavior-entry-explicit-cases.json` and `behavior-entry-explicit-before.json`:
  explicit true/false calls with distinct keywords. Final named-entry controls use
  these graphs; the original true-only graph still rejects no-argument Item.
- `conversion-cases.json` and `conversion-before.json`: RGB graphs additionally
  importing pinned Ecore, required for their WS scalar. Their keyword-only Paint
  rules do not independently qualify upstream object-construction behavior.
- `construction-cases.json` and `construction-before.json`: explicit Paint action
  counterparts, including a branch-local guarded action.
- `construction-group-cases.json` and `construction-group-before.json`: action
  before the full guarded choice, used by the final default-value controls.
  All earlier graphs remain frozen; none were rewritten to turn a failure green.

Shared native/WASM controls in `tests/acceptance/shared/xtext_inferred_contexts.rs`
exercise actual RGB values, complete stored parent/child payloads, source-backed
computed reads/writes, default and named entries, original-source replay, checked
archive rebuilding, missing/stale providers, stale contracts/sources, unrelated
behavior, package-borrow mismatches, admission limits and atomic rejection.
`tools/test_xtext_inferred_context_evidence.py` checks frozen bytes and identities.

Executable providers remain installed by the caller. Source recipes record no
executable implementation. JSON host catalog activation, browser authoring,
project/restart adoption, broader resource/provider forms and independent upstream
qualification remain separate work.
