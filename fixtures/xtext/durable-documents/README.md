# Durable document verification evidence

This corpus preserves exact original source graphs, generated verification
artifacts, full observations, native expected results and failed attempts for
the private NativeV65 increment. It is verification data, never executable
authority. Production rebuilds source/schema/provider context before adopting
models, archives or node links. Java is an optional independent oracle only.

Run `python verify.py --negatives` from any working directory. It uses Python's
standard library and reads only this corpus. `--repository PATH` also compares
the fourteen unchanged consumer fixtures at their pinned repository paths.
There is no dependency on an ignored `target` directory for pure verification.

`origins*.json` map every historical relative path to exact bytes in `blobs/`.
Identical files share a SHA-256 blob; original names and their separate roles
remain explicit. Existing raw sources, generated Java/classes, stdout/stderr,
process status, partials and requests have not been normalized. Original paths
inside those files remain historical data. No JARs are vendored. The sixty
original runtime JAR digests and sixty-six original license/notice entries are
preserved; extracted upstream Java keeps its original copyright headers.

`derivations-v1.json` and its source-binding addendum connect 969 complete consumer fields to exact whole raw
upstream or native observation objects. The verifier checks both actual values
and the source objects, without excluding errors, nodes or accounting fields.
It separately checks 388 original node observations, 104 named parse-stage
observations, 26 construction observations, exact lone-surrogate u16 carriers,
and source envelope hashes. A lossless observation carrier does not establish
UTF-16 support for native production strings. Raw ANTLR `getLookAhead` counters
remain preserved and unqualified; native prediction dependencies are separate.

The original 2,147-request baseline and both latest complete native/WASM captures
are stored using deterministic gzip (empty filename, mtime zero). Decompression
must reproduce exact raw lengths and hashes. All 4,294 captured rows compare the
whole native and WASM result to the original result, including errors and fees.
The exact corpus inventory is in the preserved receipts; this is not evidence
for every possible V1–V64 obligation. The separate 128-request archive/typed ABI
record and replay also compare whole outcomes.

The native fixtures and browser goldens have distinct provenance. Browser
goldens are complete native dispatcher observations, not independent upstream
semantics. Typed RGB observations use the explicitly supplied verification
converter, not Xtext's default converter. Original typed/default-converter,
source/generator, diagnostic, class-loader and transport failures remain
separate, along with the former accounting and trailing-token regressions.

The simple-actions absent-selector request failed transport: it executed no
model probes. Its earlier success credit was withdrawn. The executable
comparison is a separately identified **selected empty behavior** companion
that retains the original initializer source in its bundle. Four original
constructor goldens remain separate. The old `native_context_note` prose in the
unchanged units fixture is retained literally; source envelopes and explicit
selection, rather than that old annotation, determine its actual context.

An older separated-loader review copy omitted the original 2,506,805-byte
observation file and copied an earlier 607,642-byte file. Both that immutable
packet and its manifests are retained. The distinct `generated/xncl1/` origins
now include the exact original 2,506,805-byte file named in its receipt and in
the construction fixtures. No old receipt or observed result was repaired.

Eight reused generation roots are bound to the existing committed corpus at
`fixtures/xtext/rule-hidden-scope`. `existing-corpus-dependencies.json` pins its
extraction manifest and each original root manifest. The initial extraction
plan's shorter `hidden-scope` pathname was a naming error; that plan remains
unchanged and the explicit dependency addendum records the actual path.

To reconstruct an original helper/source/artifact subtree, run
`python materialize.py --prefix generated/xncl1/ --output NEW_DIRECTORY` (or
another exact origin prefix). The destination must not exist. This performs
byte restoration only. Original Java producers/helpers and commands are
retained verbatim. A fresh relocated source-generation/runtime replay still
needs a separately frozen explicit physical-path adapter: logical source URIs,
TypeRef resource URIs, class ownership and signed parent JARs must remain exact;
only the original bounded owned GenModel path comparison exception is allowed.
No fresh Java regeneration or portable Java execution is claimed by this pure
verification receipt.

The production/test delta is a separate guarded packet. Actual joined-source
native/WASM/worker acceptance is still required before adoption. This corpus
does not close the broader X04–X07, X15 or S09 requirements.
