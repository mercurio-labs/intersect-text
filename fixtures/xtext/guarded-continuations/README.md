# Guarded fragment in an optional continuation

Authored NativeV40 connector-shaped example using unchanged current-actions
Ecore/Rcore. An optional prefix calls a guarded fragment, then requires `from`;
two contained endpoints are separated by `to`. Both paths share an initial
endpoint spelling. Admission proves the larger language with guard restrictions
removed; it does not use the predicate to excuse overlapping paths. NativeV39
retains its explicit guarded-proof rejection. Ambiguous, malformed and exhausted
controls must reject. This is not general guarded prediction or KerML semantics.
