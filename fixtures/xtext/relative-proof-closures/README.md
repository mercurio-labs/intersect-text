# Relative proof closures

Authored NativeV42 grammar with six branching fragment levels and a shared
26-fragment tail. Left/right model rules have distinct suffixes. Proof templates
retain internal returns separately and append the exact requesting caller stack.
The old exact-context cache retains budget rejection. Native/WASM controls cover
both suffixes, source/model identity, spans, replay, budgets, malformed input and
genuine ambiguity. No full Xtext or KerML semantic qualification is claimed.
