# Terminal-negation evidence and consumers

`cases.json` and `observations.json` preserve 22 exact authored source graphs and
their pinned Xtext/ANTLR stage outcomes. Separate `nested-cases.json` and
`nested-observations.json` companions retain two additional exact graphs and six
runtime observations; the original 22 are unchanged. The oracle adapter, provenance and emitted
program evidence are verification-only. Successful extraction, linking,
generation and runtime observations are recorded separately. No Java is required
for native builds or production execution.

`native-cases.json` contains complete canonical Rcore/Xtext source/dependency
graphs for those unchanged grammars, six original NativeV56 before requests and
results, and a separate ordinary parameterized companion. It retains exact source
digests, original input bytes and the captured baseline release identity.

NativeV58 executes the proved single-unit operand path in the shared matcher.
NativeV1–V57 keep their prior behavior. Native source, JSON, public WASM and archive
consumers live in `crates/intersect-web/tests/terminal_negation.rs` and
`toolkit/tests/terminal-negation.node.js`; Python evidence checks separately pin
the original fixtures and oracle stages. See
`docs/xtext-terminal-negation.md` for the precise supported boundary and remaining
successful upstream/native disagreements. Full X05 remains open.
