# Predictive KerML terminal example

All nine terminal declarations are exact slices of the pinned KerMLExpressions
source. The original source header, license, hashes and byte ranges are retained.
The surrounding parser/metamodel is independently authored and selects the
explicit `intersect.xtext.native.v2` compiler profile. It is not a full KerML grammar.

The example yields five objects, integer counts and raw exponent strings, exact
quoted-name references, hidden notes and significant documentation. Prediction
and terminal-body recognition share one native/WASM implementation. See
`docs/xtext-day09.md` for qualification and remaining gaps. Cached upstream
controls are independent reference evidence, not fresh Java oracle runs.
