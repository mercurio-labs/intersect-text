# Nullable fragment continuations

Authored NativeV34 teaching grammar, using the unchanged compatibility graph Ecore.
Prefix and Detail may consume no text. The nested a b repetition must be proved
disjoint from both callers' a c/a d suffixes before admission. Transparent calls
and sequences introduce no extra choice; all nullable alternatives and conflicting
repetitions retain their existing shared-graph proof obligations.
Controls cover empty/nonempty prefixes, nested nullable alternatives, ambiguous
partitions, nonprogress, exact model identity/span, replay and native/WASM execution.
This is not full Xtext or pinned KerML qualification.
