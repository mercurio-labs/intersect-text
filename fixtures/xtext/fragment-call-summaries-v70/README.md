# Public fragment caller summary controls

These authored verification sources enter through the public ordinary Xtext
frontend with an exact Ecore bundle, native Ecore-to-Rcore migration and unchanged
default source policies. No Java tooling, inference shortcut, trusted structural
package or private grammar admission hook is used.

`native-reference.json` is a frozen native regression and cross-target reference,
captured by `capture_native_public_reference` in the handwritten integration
control. It is generated expected DTO data, not executable semantic authority or
an independent Xtext oracle. The entire submitted/retained bundle, native schema,
grammar and prediction programs are compared by the public controls.

- Sixty caller classes share a two-hundred-keyword typed fragment. V65 through
  V69 reject at the existing prediction-work ceiling; V70 admits the same source.
- A small source produces the exact same whole V69/V70 package after changing
  only the explicit grammar profile field for comparison.
- An unrelated second receiver is rejected by authored-source validation of imported class identity and supertypes
  with the exact same complete diagnostic under both profiles. Native private
  controls separately verify cached per-class assignment validation and fees.

The reference supplies native evidence only. Actual WASM/browser execution and
full KerML/SysML language support require separate qualification. Default limits
and all original pinned language sources remain unchanged.
