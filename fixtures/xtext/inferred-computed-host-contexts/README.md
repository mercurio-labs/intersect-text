# Inferred computed-provider host consumers

These frozen native extension cases reuse the complete original plain and
parameterized source graphs from `../inferred-contexts/behavior-entry-explicit-cases.json`.
They are not additional independent JVM observations. The full parameter,
provider/resource, X03 and Rcore/S09 acceptance contracts remain open.

`plan.json` retains every source, exact authored behavior identity and consumer
requirement. `contexts.json` pins explicit version 2 selections and the installed
`rcore.projection` version 1 provider contracts. The native host controls independently
infer the original schema and compare every contract field with these frozen bytes.
`before.json` records those complete actual requests against the verified prior
WASM from `45175c6d`: both reject the unknown `behavior` field. The prior artifact's
SHA-256 is recorded, not an invented or reconstructed failure.

Positive controls execute real backing-value writes and derived readback,
parent-child identities, default and reachable named entries, source replay,
queries, script publication and invalid-value rollback. Native controls check source archive
reconstruction. Fresh-WASM ZIP consumers check both Python forms and full
redigested forged-IR rejection,
exact behavior matching and valid retry. Actual workers check atomic activation,
stale-revision rejection and explicit source re-import after a worker restart.

Source-backed provider metadata does not install arbitrary code. The production
adapter validates the installed identity, selected behavior source and exact
writable projection, then delegates reads/plans to existing Rcore semantics and
uses SourceBoundSettings for text writes. Version 1 remains catalog-only.
The frozen host controls verify Set; collection append/unset consumers, editor
provider authoring, durable project recovery, full catalog/resource coverage and custom-value XMI/query support still need their own evidence.

Portable integrity checks freeze source identities and observations. They do
not award semantic qualification; actual host/runtime controls do that.
