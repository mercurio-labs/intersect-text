# Retained numeric payload source controls

This additive corpus preserves the original before and final source-backed
native observations. The same support consumers drive actual typed Sessions
from native and zero-import WASM. There is no alternate graph reader, numeric
kernel or callback implementation in the fixture.

The kernel companion has 11 exact source graphs: 9 compile and execute 216
unary/binary evaluations over borrowed and owned sessions, q1/q3/q256 and four
numeric policies. Two source type rejections retain their original bodies,
hashes and diagnostic spans. Complete original outcomes and fees agree; only
Pending counts are a separately retained scheduling change.

The lifecycle companion has 3 literal input cases over 2 original source graphs:
240,000-byte String, 240,000-character Bytes hex and separately identified escaped
Unicode. Its 147 rows contain 72 selected numeric-phase cancel/drop actions and
72 complete fresh recoveries. The moved versus borrowed root-input frees are
specific allocator pointer observations used only by the test process. They do
not supply execution authority or prove all descendants, OS allocation behavior
or cleanup latency. The global test allocator is not installed in model code.

The original scalar limits, logical fees, late result-node refusal ordering,
source identities and complete errors remain required. Current expectations
retain every field. The full before rows remain unchanged; the comparison
explicitly separates only evaluation Pending counts. This does not require old
poll topology to block cooperative default execution.
