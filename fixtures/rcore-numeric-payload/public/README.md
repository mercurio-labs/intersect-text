# Actual numeric worker controls

The test uses the application's language worker and execution worker, its normal
WASM artifact, and the three original String, Bytes and escaped-Unicode source
requests. The observer prefix holds actual Pending responses without changing
the worker body or its quantum of 256. Programs, complete results and cancellation
failures are checked in full. Drop, stale identities, concurrent recovery and
project replacement are separate controls.

The six selected left/right numeric measurement points are source-revision
witnesses. They were coupled through the actual catalog builder, conversion-aware
compiler, reference inputs and fresh Control(false), then persistent public
native/WASM hosts and real workers. Pending counts are not a permanent semantic
contract: a later scheduling change needs a fresh phase witness and preserved
before evidence, rather than an arbitrary count increase.

The saved project contains the workbench language and model. The numeric function
request has its own original source bundle and is submitted again after project
replacement. This does not claim those separate function sources are persisted
as part of that project. Historical absolute receipt paths inside the raw plan
are provenance only; tests never open them or use cached IDs as authority.

The JSON plan and observer are self-contained fixture inputs; the test uses no
ignored target files. General callback cooperation, equality/kernel chunking,
other source/context ownership and last-owner cleanup remain outside this proof.
Full S09 and W1–W6 gates remain open.
