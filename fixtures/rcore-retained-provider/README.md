# Retained provider validation qualification

Handwritten verification consumers call the ordinary public compiler and
EvaluationSession with actual registered conversion providers. The driver is
the formatted original source of the independently executed edge proof. No
provider is installed from serialized metadata and no production authority
comes from these recordings.

552 whole rows cover borrowed/owned movable sessions at q1/q17/q256, every
provider work/storage limit0..40, exact17/one-short16 provider work,
exact32/one-short31 cursor storage, factory/cursor failures, understated state,
malformed headers/payloads, caught work/cancellation failures, silent Finished
and exact cursor/provider release. Each current transition observes its live
control. The original before recording retains its distinct poll counts.

Run cargo test -p intersect-model --features allocation-profile --test
retained_provider_validation for exact native64 expected observations. The
standalone native/Cargo.toml builds the same consumer as a CLI or zero-import
WASM library. qualify/result_ptr return its complete observation. Native64
and wasm32 expected files retain all layouts and actual concrete cursor sizes
separately; all552 semantic rows, including polls/current observations, match.
The declared logical cursor debit is32 on both targets; physical sizeof is
32native/16WASM. Neither is inferred from the other.

This corpus does not prove universal provider preemption, allocation/destructor
costs, physical cleanup or full S09. Headers/canonical checks and opaque provider
methods retain explicit atomic boundaries. Complete suspension-prefix controls
remain separate from this edge corpus.
