# Source-certified nonconflicting repeat controls

`Qualified.xtext` is an authored native control with an explicit imported Ecore
schema. It is not an independent Xtext semantic oracle. The existing pinned
recursive-predicate oracle remains the independent commitment reference.

NativeV74 can reuse the same FOLLOW walk's existing FIRST evaluation for a
nonnullable Full direct-call `*` before an actual mandatory literal sibling.
Prepared terminal FIRST ranges conservatively exclude lexical collisions.
Proofs remain private and temporary; serialized source metadata cannot install
one. Source identities, Full operand/Call returns, repeat start/stop and the
literal exit are checked against the existing prediction graph.

Positive binding costs seven units and positive graph consumption twelve units
in the same recursive pool initialized once to 10,000. Every guarded `/repeat`
queried during classification pays one lookup unit even when no proof exists.
FOLLOW candidate/symbol/terminal/interval/source checks and retention use their
original shared FOLLOW pool. Failed work is never refunded or reset.

NativeV73 and earlier keep their old paths. The existing seven-category work
observer reports NativeV74 as `RepeatCertificateAnalysisUninstrumented`; its
categories cannot account for these new fees. Ordinary phase observations still
report the actual single pool including prior binding work.

NativeV74 also explicitly opts into the shared Full replay verifier's sufficient
guard-overapproximation proof for unprioritized decisions. The proof can remove
guard restrictions only to prove disjointness of larger languages. Actual
ordered guards, commitment, operand boundaries, call/returns and replay still
execute in the same predictor with its unchanged shared runtime allowance and
static ceilings. Hidden/unbound guards and overlapping enlarged languages reject.
This removes the separately preserved NativeV73 conservative runtime refusal for
the intact nested brace/repeat fixture; it does not rewrite or simplify it.

Low-level `predict_with_replay_input_and_completion_verification` callers select
an explicit capability. The ordinary checked package path selects it only from
NativeV74. Existing public prediction/probe APIs and every older profile remain
Legacy; serialized proof/program/source metadata alone cannot enable the mode.
The compiler's required-call proof keeps its existing Legacy scope facade.
The public controls retain the exact old whole error, whole package/program
compatibility, intended Root construction/spans, malformed rollback, small
runtime limits and the original pinned independent Full-predicate oracle rows.
